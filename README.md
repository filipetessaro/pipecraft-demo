# Pipecraft demo

A packaged Windows build of the Pipecraft demo: unzip and run `PipecraftDemo.exe`. No engine needed.

Pipecraft is a pipe, duct and cable plugin for Unreal Engine 5.6, 5.7 and 5.8: draw runs in the viewport and the elbows,
tees, flanges and supports fit themselves, in the editor or while the game runs, replicated. The demo is the in-game side,
in a machine room.

## Keys

| Key | What it does |
|---|---|
| Left click | A point of a new pipe (hold Shift for a run that is not square) |
| Right click / Enter | Lay the pipe |
| Backspace | Take the last point back |
| R | Route a pipe from the last point to where you look |
| 1 to 6 | Kit: Industrial, PVC, Large, Duct, SciFi, Tray |
| K | Give the kit to the whole run you look at |
| E | Valve on a pipe, switch on a cable |
| C | Cut a rope |
| Q / Z | Winch a rope in / out |
| Delete | Take away a pipe you laid |
| F5 / F9 | Save / load |
| H | Hide the keys |
| WASD, mouse, Space | Walk, look, jump |

## What to try

- End a pipe on the side of another: it joins with a tee. End it on another's end: a coupling.
- Place one point, look at the far side of the tanks and press R: the pipe finds its own way round them.
- Look at the blue Industrial pipe and press E: the machine loses its water and the light on its panel goes red.
- Press E on the cable along the front wall: the lamp goes out.
- Look at the crate's rope and hold Q: it lifts 100 kg. Then press C.
